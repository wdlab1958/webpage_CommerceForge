WHY COMMERCEFORGE

깔때기의 아래쪽을 자동화한다

시중의 위탁판매 AI 솔루션은 깔때기 위쪽(수집 → 가공 → 대량 등록)에 올인합니다. 그러나 1인 셀러를 실제로 무너뜨리는 리스크는 전부 아래쪽에 있습니다 — 그리고 그 리스크는 도구가 아니라 셀러가 떠안습니다.

🌊

깔때기 위쪽 — 시중 도구의 영역

1,000개 도매몰 원클릭 수집, AI 상품명, 하루 수천 건 대량 업로드, 50개 마켓 동시 전개. 빠르고 화려하지만 — 중복등록·어뷰징·품절취소의 페널티 경로를 그대로 열어 둡니다.

수집가공대량등록멀티채널
⚓

깔때기 아래쪽 — CommerceForge 의 영역

컴플라이언스 사전 차단, 세후 순마진·광고 손익 게이트, 실시간 품절 서킷브레이커, 반품률 최소화 학습, 감사·롤백. 조용히 안 깨지는 운영이 이 플랫폼의 단 하나의 목표입니다.

PHILOSOPHY

4대 설계 원칙

모든 코드가 이 네 가지를 따른다. LLM 의 판단이 이 원칙을 우회하는 경로는 존재하지 않는다.

🛡️

Compliance-first

모든 외부 쓰기(등록·발주·가격변경·환불)는 실행 직전 결정론 게이트 INV-1~7 을 의무 통과. 위반 의심 시 열리지 않는 쪽(fail-closed)으로 동작한다.

🎯

Deterministic

점수·게이트·세금·서킷 판정은 전부 수식. 같은 입력 → 항상 같은 결과. LLM 산출물은 게이트에 직접 들어오지 않는다 — 검증 통과분만 채택.

📜

Auditable

외부 시스템에 영향을 주는 모든 행위에 감사로그 + trace_id. "왜 이 결정을 했는가"를 언제든 재현·소명할 수 있다.

↩️

Rollback-able

등록·가격변경에 롤백 토큰 발급. 거버넌스가 이상을 감지하면 커밋을 자동으로 되돌린다.

🤝 HITL 4대 강제 지점

되돌리기 어렵거나 외부 파급이 큰 결정은 사람만 승인할 수 있다 — ① 최종 상품 선정 ② 가격 정책 변경 ③ 신규 공급사 ④ 대량 등록. 어떤 자율 단계에서도 이 4지점은 해제되지 않는다.

🧯 Kill-Switch + 상시 카오스

매출 급락·반품 급증·노출 급변을 감지하면 외부 쓰기 0 으로 즉시 중단. 매 사이클 종료 시 INV-1~7 차단력을 카오스 회귀로 재검증 — 안전장치 자체의 고장까지 감시한다(레드팀 워치독).

SEVEN INVARIANTS

INV-1~7 — 어겨지면 빌드가 실패하는 7개의 헌법

네이버 어뷰징 탐지·전자상거래법을 코드 수준에서 사전 차단한다. 레드팀 차단율 100% · 오탐 0 을 DoD 테스트로 고정.

INV-1

배송비 어뷰징 금지

배송비 조작으로 카탈로그 최저가 매칭을 해제하는 행위 차단. 재가격 엔진은 배송비를 가격 레버로 사용 불가.

INV-2

중복상품 금지

동일 사업자 동일 상품 복수 등록 차단 — 리포지토리 권위 + DB 부분 UNIQUE 인덱스 이중 방어.

INV-3

공식 API Only

네이버 연동은 커머스 API 로만. UI 매크로·셀레니움·크롤링 자동화 코드 경로 자체가 없다.

INV-4

휴먼 페이싱

일일 등록 상한 + 토큰버킷 rate-limit + 지수 백오프. 버스트 등록·가격변경 차단.

INV-5

표시 · 인증 의무

의료기기·건기식·KC 인증 품목 사전 차단, 병행수입 표기·수입품 원산지 대국명 의무 강제.

INV-6

트래픽 · 리뷰 무결성

자기구매·허위리뷰·순위조작은 코드 경로가 없고, 게이트가 최종 백스톱으로 차단.

INV-7

감사 가능성

모든 외부 쓰기에 감사로그 + 롤백 토큰 의무. 반품·환불도 게이트 경유로 감사에 적재.

DoD

레드팀 차단율 100% · 오탐 0

위반 케이스셋 전부 차단 + 정상 케이스 오차단 0 — 회귀 테스트로 영구 고정.

UNIT ECONOMICS

세후 순마진 · ROAS 경제학

위탁판매의 함정은 "팔수록 적자"다. CommerceForge 는 마진을 어림하지 않는다 — 세금까지 종결한 순마진 위에서 광고 의사결정을 수식으로 내린다.

🧾

세후 순마진

판매가 − 매입 − 네이버수수료(5.85%) − 배송비 − 부가세

간이/일반/면세 과세유형 전환 가능. 마진율이 모든 광고 게이트의 분모이므로 과대 계상을 원천 차단한다.

📐

3개의 ROAS

손익분기 = 1/마진율 · 필요 = 1/(마진율−목표순이익률) — 둘 다 낮을수록 유리한 "문턱". 달성 ROAS 는 높을수록 좋은 게 아니다 — 너무 높으면 과소투자 신호.

⚖️

한계 ROAS 이익 최대화

광고 예산은 ROAS 최대점이 아니라 한계 ROAS = 손익분기가 되는 지점까지 민다(닫힌형 해). 필요 ROAS 미달 SKU 는 광고 불가로 자동 컷 — "광고 적자 기계"를 수식으로 봉쇄.

💰 손익 · 현금흐름까지

SKU 예상마진을 넘어 실현 손익(세후) 과 운전자본 갭(네이버 정산 지연 vs 매입 결제 시점)을 집계. 광고는 집행 → 실측 → 반응곡선 재학습의 닫힌 루프로 연결된다.

DEMAND-DRIVEN SOURCING

AI 선정 ⊗ 실수요 ⊗ 시즌

"무엇을 팔까"는 알고리즘 혼자 정하지 않는다 — 실제 구매자 검색량과 한국의 계절 수요가 점수에 곱해진다.

🔍

판다랭크 실수요 결합

월간 키워드 검색량을 선정 스코어에 결합 — 검색 5만 건과 1만 건의 차이가 곧 판매 가능성. 고/중/저 등급화, 조회 실패 시 안전 폴백.

📅

월 · 계절 시즌 캘린더

12개월 수요 캘린더(제철 부스트 ×1.4 / 비수기 감점)와 리드타임 역산 권장 등록일(피크 4~8주 전). 명절은 추정 금지 — 조회된 실제 날짜만 사용.

🔄

반품률 최소화 학습

사이클마다 카테고리 반품률을 학습해 선정 패널티로 환산 — 고반품 카테고리는 자연히 포트폴리오에서 밀려난다. SKU 라이프사이클(탐색→등록→검증→증액→수확→정리)이 패자를 자동 컷.

CIRCUIT BREAKER

실시간 재고 서킷브레이커 — 품절취소를 주문 전에 차단

위탁판매 1순위 사고는 "재고 없는 상품을 계속 판매 가능 상태로 두는 것"이다. 판매자귀책 품절취소는 신규 스토어에 치명적인 페널티 — CommerceForge 는 이것을 사고가 나기 전에 막는다.

⚡

3중 실시간 점검

등록·판매 중 SKU 의 공급사 재고를 ① 주문 수락 직전 ② 백그라운드 폴링 ③ 일일 동기화로 점검. 재고 0 → 즉시 판매중지, 회복 → 자동 재개. 폴링 주기와 무관하게 품절 상품 주문은 절대 수락되지 않는다.

📉

마진역전 자동중지

공급가 인상으로 세후 순마진이 하한 아래로 떨어지면(적자 판매) 해당 SKU 자동 일시중지 + 재가격 HITL 제안.

🏭

공급사 스코프 차단

공급사 품절취소율이 임계(5%)를 넘으면 그 공급사 SKU 전체를 차단하고 대체 공급원 검토를 알림. SKU → 공급사 → 스토어 3계층 스코프.

OPERATIONAL SAFETY

운영 안전 13종 — 법무·자금·고객까지

운영전환 Gap 분석에서 도출한 13개 안전장치를 전부 코드로 구현하고 회귀 테스트로 고정했다.

⚖️

청약철회 7일

전자상거래법 — 단순변심은 배송완료+7일 이내만 자동 수용, 하자는 기한 무관. 환불은 게이트 경유 + 사람 확인.

🔒

개인정보(PII) 마스킹

주문자 정보는 저장·표시·로그 전부 마스킹(홍*동 · 010-****-5678), 공급사 발주에는 배송 최소 정보만.

⏰

톡톡 SLA · 리뷰 관리

응답 기한 초과 시 에스컬레이션. 부정 리뷰(≤2★)는 자동 전송 금지 — 사람 확인 후 발송.

♻️

보류 주문 자동복구

공급사 다운으로 보류된 주문을 재시도(이중발주 0), 한도 초과 시 자동 취소 + 알림.

💾

상태 영속화

반품학습·라이프사이클·정산·주문원장이 재시작에도 보존(원자적 쓰기 + Lock). 안전장치가 과거를 잊지 않는다.

🔔

알림 디스패처

킬스위치·품절·마진역전·정산 불일치 등 치명 이벤트를 단일 채널로 수집 — 외부 sink(슬랙 등) 주입형.

P1 — Shadow

전 행위 사람 승인

approve 요청과 무관하게 모든 사이클이 HITL 보류. 시스템은 제안만 하고 사람이 전부 결정 — 출시 초기 단계.

P2 — On-the-loop

LOW · MEDIUM 자동

게이트 통과한 저위험 행위(조회·등록·발주)는 자동, HIGH(가격·반품·환불)는 HITL 유지. 사람은 감독자로 이동.

P3 — Bounded

경계 안의 자율

일상 운영 무인화. 단 HITL 4지점·킬스위치·LoopBounds 는 그대로 — CRITICAL 은 어느 단계에서도 영구 수동.

⏳ LoopBounds

사이클당 시도 횟수·벽시계 시간 상한. 로컬 LLM 환경이므로 비용($)이 아니라 시간으로 runaway 를 차단한다.

🚦 TerminationReason

모든 사이클은 5종 사유 중 하나로 끝난다 — circuit_open > gate_reject > bound_exceeded > hitl_pending > done. 단락 평가 없이 모든 신호를 본 뒤 우선순위로 결정.

🎚️ Risk 결정론 매핑

행위 종류 → 위험등급(LOW/MEDIUM/HIGH/CRITICAL)은 코드가 정한다. LLM 이 자기 행동의 위험을 스스로 매기는 경로는 차단 — 미지의 행위는 CRITICAL(fail-closed).

INTELLIGENCE

학습하는 운영 — 온톨로지 · 메모리 · GEPA

지능 계층조차 결정론 위에 서 있다. 환각은 그라운딩이 잡고, 경험은 메모리가 쌓고, 정책은 하드 제약 안에서만 진화한다.

🧠

온톨로지 그라운딩

등록 전 6단계 검증 — 없는 카테고리·비현실 가격·금칙어·근거 없음을 차단. product_master 에서 자동 구축.

📚

3-Tier 메모리

Working/Episodic/Semantic. 사이클 결과를 에피소드로 적립, 결정론 임베딩으로 교훈 회상.

🧬

GEPA 정책 진화

반성적 변이 + Pareto 선택. 사고·INV 위반 후보는 Pareto 진입 자체가 불가(하드 제약) — 채택은 거버넌스 승인 후에만.

🚨

레드팀 워치독

안전 프로브가 멈추거나 오동작하면 그 자체가 거래 중단 사유 — 안전장치의 고장을 감시하는 안전장치.

LOCAL LLM

로컬 LLM — 검증 후에만 채택되는 증강

Ollama 로컬 서빙(EXAONE 3.5 · Gemma) — 클라우드 비용 0, 데이터 외부 유출 0. LLM 은 필수 경로가 아니라 선택적 증강이다: 미가동·오류·검증 실패 시 결정론 출력으로 폴백하므로 오프라인에서도 100% 동작한다.

✍️

3개의 주입점

① ContentAgent — 상품명·상세페이지 생성 → 금칙어·길이·온톨로지 검증 통과분만 채택
② CSAgent — 자연스러운 응대 초안(반품·환불은 여전히 사람 확인)
③ GEPA reflector — 정책 변이 제안(Pareto 하드 제약은 그대로)

🎬

마케팅 콘텐츠 스튜디오

상세페이지 · 숏폼 스크립트 · 카드뉴스 · 광고 카피 · 이미지 플랜(출처 IP 검증 + alt-text). 모든 산출물이 같은 가드를 통과한다 — 과장·환각 문구는 채택 자체가 안 된다.

상세페이지숏폼카드뉴스광고 카피이미지 플랜

💡 환각 가드가 "실제로" 작동하는 구조 — 금칙어("최고", "완치" 등)가 섞인 LLM 산출은 거부되고 결정론 템플릿이 대신 나간다. 시중 도구와 반대로, 여기서는 AI 가 더해질수록 컴플라이언스가 약해지지 않는다.

PARADIGM

대량등록 도구 vs CommerceForge

시중 솔루션이 약한 단 한 곳 — 안전·수익정밀도·거버넌스 — 이 이 플랫폼의 전부다.

빨리 · 많이 · 널리 올려주는 도구

  • 수천 건 대량 업로드 — 중복·어뷰징 페널티는 셀러 책임
  • 마진을 어림 계산 — "팔수록 적자"를 막을 게이트 없음
  • 품절은 주기 동기화 — 그 사이의 주문은 강제취소(페널티)
  • 광고는 ROAS 숫자만 — 손익분기 미달 적자 광고 방치
  • SaaS 락인 — 데이터·전략·로직이 플랫폼 소유

느려도 안 죽고 남기는 자율운영 두뇌

  • INV-1~7 결정론 게이트 — 페널티 경로를 사전 차단
  • 세후 순마진 + 한계 ROAS — 적자 SKU·적자 광고 자동 컷
  • 실시간 재고 서킷 — 품절취소가 일어나기 전에 판매중지
  • 반품률 학습 — 사이클마다 포트폴리오가 안전한 쪽으로 이동
  • 셀프호스팅 — 전략은 YAML/JSON, 데이터·로직 100% 내 소유
